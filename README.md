# Определение цвета предмета по фотографии

Первая версия для мини-склада: Python + OpenCV, без обучения нейросети.
Программа выделяет один светлый или цветной предмет на чёрном конвейере
и определяет его цвет, исключая фон.

## Установка и запуск

Нужен Python 3.10 или новее. В терминале из каталога проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python color_detector.py
```

В Windows активация окружения: `.venv\Scripts\activate` (cmd) или
`.venv\Scripts\Activate.ps1` (PowerShell); вместо `python3` обычно используется `python`.

Положите фотографии в папку `photos/` рядом с программой и запускайте без аргументов:

```bash
.venv/bin/python color_detector.py
```

Программа обработает все JPG, JPEG, PNG, BMP, WEBP и TIFF в этой папке
(без вложенных папок). Файлы остаются на месте; при каждом запуске обрабатываются
все фотографии заново. Если папка пустая, программа попросит добавить фотографии.
Ошибка в одном файле не мешает обработке остальных; при наличии ошибок код выхода — 1.
Папки `photos/` и `output/` по умолчанию определяются относительно файла программы,
поэтому запуск из другого рабочего каталога тоже работает.

При необходимости можно по-прежнему указать отдельную фотографию или другую папку:

```bash
python color_detector.py "/путь/к/фотографии.jpeg"
python color_detector.py "/путь/к/папке"
```

Проверено на фотографии Apple Pencil на чёрном коврике: **белый**, доля основного
цвета **90,2%**, медианный RGB **[225, 224, 212]**. Контур проверен визуально:
коврик и светлый стол по краям снимка не входят в выделенный предмет.

В терминале появятся название цвета, доля пикселей этого цвета и медианный RGB.
Каждый запуск создаёт в `output/` отдельную папку с датой и временем
начала обработки: `ph_ММ.ДД ЧЧ.ММ` (без года и секунд).
Время всегда в **UTC+3**, независимо от часового пояса компьютера. В ней сохраняются:

- `ИМЯ_result.jpg` — фотография с контуром предмета и названием цвета;
- `ИМЯ_mask.png` — маска: белым выделен предмет, чёрным фон;
- `ИМЯ_result.json` — цвет, распределение цветов и имя исходной фотографии (`source_file`).

Например:

```text
output/
  ph_09.18 10.35/
    ph_09.18 10.35_result.jpg
    ph_09.18 10.35_mask.png
    ph_09.18 10.35_result.json
  ph_09.18 10.37/
    ph_09.18 10.37_result.jpg
    ph_09.18 10.37_mask.png
    ph_09.18 10.37_result.json
```

Путь к папке текущего запуска выводится в терминале. Если имя папки уже занято
(например, при нескольких запусках за минуту), добавляется номер: `_02`, `_03` и т. д.
Прошлые результаты сохраняются. Для пустой входной папки папка запуска не создаётся.
Основной каталог можно изменить через `--output-dir results` — папки запусков
будут создаваться внутри него.
Если фотографий несколько, к имени каждого комплекта добавляется номер фотографии:
`ph_09.18 10.35_01_mask.png`, `ph_09.18 10.35_02_mask.png` и т. д.
Фотографии нумеруются в порядке сортировки по имени. Соответствие исходнику
видно в терминале и в поле `source_file` JSON-файла.

## Как выбирается предмет

Алгоритм рассчитан на **чёрный фон**. Чёрная лента при освещении может выглядеть
серой, поэтому порог яркости подбирается по снимку методом Оцу, но не опускается
ниже 95 по шкале 0…255. Светлые пиксели выше порога считаются кандидатами на предмет.
Насыщенные цветные пиксели выделяются дополнительно: насыщенность от 65,
яркость от 65, разница максимального и минимального канала от 40.
Это помогает находить, например, тёмно-синий предмет на тёмной ленте.

Медианный фильтр подавляет мелкую фактуру фона. Из связных областей выбирается
самая крупная, не касающаяся границы кадра или ROI. Так светлый стол за краями
коврика не попадает в результат. Мелкий шум отбрасывается по площади. Маска
дополнительно проверяется по исходным пикселям, чтобы сглаживание не добавляло
тёмный фон. Изображение не уменьшается перед выделением тонких предметов.

Предмет должен целиком находиться внутри кадра/ROI с небольшим запасом до границ.
Алгоритм выделяет предмет по внешнему виду и не определяет, что это именно Pencil.
Цвет вычисляется только внутри маски; прямоугольная область вокруг предмета
не используется для подсчёта цвета.

Если объектов несколько или фон сложный, укажите прямоугольник вокруг нужного
предмета с небольшим запасом фона: `--roi X Y WIDTH HEIGHT`.
Координаты задаются в пикселях исходного снимка после применения EXIF-ориентации;
начало координат — левый верхний угол.
Весь предмет должен попасть внутрь прямоугольника.

```bash
python color_detector.py photo.jpg --roi 100 600 1700 950
```

Это пример координат для крупного снимка; для своего изображения их нужно подобрать.

## Как определяется цвет

После выделения объекта программа немного отступает от его контура и переводит
пиксели в HSV. Цветовой тон определяет красный, оранжевый, жёлтый, зелёный,
голубой, синий, фиолетовый, розовый и коричневый. Яркость и насыщенность позволяют
отдельно выделять чёрный, серый и белый. Побеждает наиболее частый класс.
Пороговые значения находятся в функции `classifyPixels` в `color_detector.py`.

`dominant_share` — доля пикселей основного цвета, **не вероятность правильного
распознавания**. При доле ниже 60% результат отмечается как `ambiguous`:
предмет может быть разноцветным или маска неточной. RGB — медиана пикселей
победившего класса в порядке красный, зелёный, синий.

Это прототип для одного хорошо различимого предмета на чёрном фоне.
Чёрные предметы и почти чёрные участки исключаются вместе с фоном; первый пример
с чёрной мышкой на светлом столе больше не соответствует рабочему режиму.
Сильные блики на ленте, цветное освещение, малый контраст, прозрачные предметы
и яркий мусор могут приводить к ошибкам. Пороги нужно проверить на реальных
образцах при освещении склада. Если предмет касается края, он исключается;
дождитесь его полного появления в рабочей области.
Сначала проверяйте маску — она показывает, какой участок анализируется.

## Дальнейшее подключение камеры

`detectColor(image, roi=None)` принимает BGR-кадр NumPy и возвращает словарь
результата и маску. Его можно использовать для кадров OpenCV без изменения
классификации цвета. Захват видео в эту версию пока не входит.
Для конвейера следующим шагом стоит зафиксировать область анализа и освещение,
снять пустую ленту и образцы всех нужных цветов. Это позволит настроить выделение
предметов и цветовые пороги. Скорость обработки непрерывного видео ещё не измерялась.

## Проверка

```bash
.venv/bin/python -m unittest discover -s tests -v
```

Тесты проверяют основные цвета на чёрном фоне, тонкий белый предмет на текстурном
коврике с неравномерным освещением и светлыми краями, тёмные насыщенные цвета,
исключение чёрных отверстий, выбор предмета через ROI, разноцветный предмет,
пустой кадр и неверные координаты.
